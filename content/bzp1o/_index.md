今天继续学习梅花易数

八卦和五行

四个一看就明的对应：坤为地，属土；艮为山，属土；离为火，属火；坎为水，属水；

不大明的四个：乾兑属金，乾为天，日出入金属光泽，兑为泽，看似水，实则为金，因为西方属金，目前只能死记，暂不知道缘由，需要后续学习到方位才好弄懂。震巽属木，震为雷，春雷一响，草木惊醒，巽为风，春风一吹，草木生长。

下为 ai 给的表格：


| 卦   | 五行  |
| --- | --- |
| 乾、兑 | 金   |
| 震、巽 | 木   |
| 坤、艮 | 土   |
| 离   | 火   |
| 坎   | 水   |
